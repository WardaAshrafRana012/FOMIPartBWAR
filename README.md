# Fomi — Continuity

Part B · **Video Generation Workspace**

A professional creative director returns to **AFTER HOURS — Fragrance Campaign**, an existing four-shot film. Continuity keeps the relationship between the brief, project-level Creative DNA, individual shot directions, alternatives, and editorial decisions visible.

This is a functioning frontend demonstration, not an AI video service. Original local motion studies stand in for generated clips. Creative DNA changes the submitted request and stored metadata; it does not guarantee visual consistency.

## Run

Node.js 20.9+ (tested with 24), npm, no keys or accounts required.

```sh
npm ci
npm run dev -- --port 3100
```

Open **http://localhost:3100**. Port 3100 deliberately avoids a separate app on port 3000. On Windows use `npm.cmd` if PowerShell blocks npm.ps1.

```sh
npm run build
npm run start -- --port 3100
```

## Try the complete workflow

1. Open the seeded campaign; read its brief from the storyboard.
2. Edit Creative DNA. Existing takes acquire an “Earlier DNA” label when their saved DNA differs.
3. Select a shot, edit its direction, and optionally expand shot overrides/reference. Open Effective direction to read the combined request.
4. Generate two alternatives. Status moves from queued to generating to completed. Keep editing another shot while it runs. New results never change a chosen take.
5. Compare takes, choose one for the sequence, and record a decision note.
6. Review sequential playback. Export the JSON package; download individual clips from Take details.

To test failure, expand overrides and enable “Demonstrate generation failure.” Cancellation and failure both expose Retry. An invalid prompt produces a route validation error. Reset demo requires confirmation.

## Architecture

- `app/`: App Router shell, error/loading boundaries, `api/generate/route.js`.
- `components/workspace/`: workspace composition, storyboard, direction editor, media, comparison and sequence review.
- `components/ui/Dialog.js`: native modal dialog with accessible title, keyboard trap, Escape and focus restoration.
- `hooks/useProject.js`: versioned browser persistence and debounced save feedback.
- `hooks/useGeneration.js`: independent per-shot jobs, cancellation, request handling, and local stage timers.
- `lib/project.js`: effective-direction merging, request snapshots, validation, order changes, recovery and package export.
- `data/seed.js`: realistic brief, DNA, four shots, eight takes and initial selections.
- `public/demo/`: original local SVG posters and WebM fixtures, approximately 1.6 MB of video in total.
- `tests/` and `scripts/verify-browser.js`: meaningful data tests and actual browser workflow checks.

JavaScript only; global CSS with responsive breakpoints and reduced-motion support. Dependencies are Next.js, React, and Lucide icons; tooling includes Playwright, Prettier and PDFKit. No external fonts, network media, database or authentication.

## Mock generation

`POST /api/generate` validates prompt length, supported duration and aspect ratio, and all effective DNA fields. A stable hash of the prompt chooses two curated fixture paths. The response contains IDs, timestamp and an immutable copy of the submitted request. The client simulates stages (about four seconds), not model-accurate percentages. Explicit failure is a client simulation after a valid response. There is no job queue or server persistence.

One request per shot can run at a time. AbortController cancels fetches; later timer callbacks check cancellation before adding takes. Unmount cleans up timers and controllers. Reload cancels unfinished simulations: no background task resumes, no incomplete take is saved, and existing selections remain. Editing DNA or switching projects during a job does not alter its submitted snapshot or destination.

## Persistence

`localStorage['fomi-continuity-v1']` contains `{version: 1, active, projects}`. Projects retain brief, DNA, ordered shots, selected shot, takes, preview/sequence choices, and notes. Writes debounce for 500 ms, with a pagehide flush. Saving/Saved/Save failed describes **this browser**, never server storage. Malformed or incompatible schemas recover to the seed with a visible notice. Storage denial/quota errors show failure feedback. Different browsers, profiles, devices and origins have independent workspaces. No cross-tab conflict resolution; last writer wins. Export JSON for a durable copy. Package import is intentionally outside scope.

## Vercel and GitHub

This folder is independent of the existing AI Video Studio. Use this folder as the repository root.

1. Create an empty GitHub repository in your intended account. Commit these files and add that repository as `origin`, then push `main`.
2. In your intended Vercel account, import that repository. Framework: Next.js. Root: repository root (or `fomi-continuity` if importing the parent folder). Build: `npm run build`. Use the lockfile; no environment variables or custom backend needed.
3. Deploy, open the resulting HTTPS URL and verify generation and export. Do not use static export: the POST route needs the Next.js runtime.
4. Replace `PENDING — deploy to intended Vercel account` and `PENDING — publish GitHub repository` in `docs/submission-links.json`, then run `node scripts/create-submission.js` to regenerate the PDF.

Framework reference: [Next.js route handlers](https://nextjs.org/docs/app/getting-started/route-handlers) and [Vercel Next.js deployment](https://vercel.com/docs/frameworks/full-stack/nextjs).

## Limitations

Four curated clips are reused across alternatives. Prompt, duration, aspect ratio, DNA and reference affect saved requests, not fixture pixels or encoding. All actual clips are approximately five seconds and landscape; the UI explicitly calls entered durations planned metadata. Sequence playback is consecutive clips with browser transitions, not frame-accurate editing or a rendered film. No AI consistency claim, MP4 renderer, collaboration, cloud backup, authentication, package import or undo history. Delete/reset are confirmed. Unsaved edits can be lost on browser crash within the debounce interval.
