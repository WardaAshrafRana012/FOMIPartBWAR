# Media provenance

`amber`, `veil`, `ritual`, and `signature` each have an SVG poster and a WebM motion fixture. All artwork is original geometry, gradients, typography and canvas movement authored in `scripts/create-media.js` for this project. No third-party photography, copyrighted film, model weights or downloaded stock clips were used.

The palette, fictional amber fragrance and lighting are deliberately shared. Movement differs through a slow push, framing, bottle rotation, and light sweep. These are stylized editorial motion studies, not photorealistic footage or AI model output. The deterministic API reuses them; request settings do not alter them.

Resolution 960 × 600; approximately five seconds; VP9 WebM; silent. Chromium and Firefox support WebM; other browsers have an explicit unavailable-media fallback. Playback compatibility on real Safari/iOS has not been verified. Posters are SVG rendered through next/image with optimization disabled. Thumbnails never autoplay; videos preload metadata only. Each actual clip is approximately 0.4 MB.
